# 아리with 제2화 연속성 점검
- 공개된 이전 회차: 제1화 「허용 오차 · 벨트 위의 아이」.
- 핵심 수정: 아리는 누군가에게 목적지를 지정받아 보내진 아이가 아니라, 공장 장부에 ‘폐기’로 처리된 뒤 지상에 버려진 아이로 묘사한다.
- 순덕은 첫눈 내리는 땅끝골에서 버려진 아리를 발견하고 직접 움막으로 데려온다.
- 순덕은 아리의 출생과 공장의 존재를 전혀 모른다.
- 시기: 기원전 500년 무렵. 현대 도구와 현대 지명 사용하지 않음.
- 아리: 오른손 새끼손가락 없음, 한쪽 다리의 비대칭 유지. 몸의 차이를 사랑으로 고치지 않음.
- 사랑 한 숟가락: 노동자가 의미를 알지 못한 채 더한 아주 작은 마음의 몫. 위대한 구원 행위처럼 설명하지 않는다.
- 공장의 목적, 인간 생산의 진짜 이유, 상층 존재의 정체는 초반에 직접 해설하지 않는다.
- 공장이 아리 출고 직후 폐쇄됐다는 설정은 사용하지 않는다.
- 제2화 주요 장면: 폐기 판정 → 어둠 속 통로 → 첫눈 속 버려진 아리 → 순덕의 발견 → 움막으로 귀가 → ‘내 손 여기 있다’.
- 기존 삽화 4장은 위 흐름에 맞춰 캡션을 수정해 계속 사용한다.
- 다음 연재: 제3화 「기다리는 손」. 이름 짓기는 이후 순서로 유지.
